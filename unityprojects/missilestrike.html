Missile Strike

A fast‑reaction defense game built in Unity. I created all of the code and art assets, including the missile, UI, effects, and gameplay systems.

Overview

Missile Strike is a reaction‑based defense game where players launch a missile from the silo and manually guide it to destroy incoming enemies. The game focuses on fast input, directional control, and timing. I created all of the visual assets and coded the gameplay systems, including missile steering, enemy behavior, and survival logic.

Features

  • Manual missile steering using click‑and‑drag controls
  • Increasing difficulty as enemies approach faster
  • Fully custom art assets and UI
  • Responsive input system for real‑time direction changes
  • Survival‑based gameplay loop

Development Notes

This project helped me explore real‑time input handling, projectile steering, and timing‑based gameplay. Building both the visuals and mechanics allowed me to create a cohesive experience where the controls and art style support the fast‑paced action.
