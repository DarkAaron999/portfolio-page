Missile Strike

A fast‑reaction defense game where you launch and steer a missile to intercept enemies before they reach the silo.

Overview

Missile Strike is a reaction‑based defense game built in Unity. Your goal is to launch a missile from the silo and manually guide it to destroy incoming enemies. I created all of the code and art assets for this project, including the missile, UI, effects, and gameplay systems.

Features

  • Manual missile steering using click‑and‑drag controls
  • Increasing difficulty as enemies approach faster
  • Fully custom art assets and UI
  • Responsive input system for real‑time direction changes
  • Survival‑based gameplay loop

Play the WebGL Build

The game is fully playable in your browser through the embedded itch.io WebGL build below.

Development Notes

This project helped me explore real‑time input handling, projectile steering, and timing‑based gameplay. Creating both the visuals and the mechanics allowed me to design a cohesive experience where the controls and art style support the fast‑paced action.
