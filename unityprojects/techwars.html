Tech Wars

A 3D top-down tower defence game built in Unity. All visual assets were created by me, with gameplay systems expanded from a Baskey tutorial foundation.

Overview

Tech Wars is a fast-paced 3D top-down tower defence game where players must strategically place defences and survive waves of enemies. I created all of the visual assets myself, including the environment, towers, enemies, and UI elements. For the scripting foundation, I followed a Baskey tutorial series to understand the core tower defence mechanics, then expanded the systems with my own design decisions, balancing, and gameplay adjustments.

Features

  • Fully custom 3D assets created specifically for this project
  • Top-down camera system optimized for readability and gameplay clarity
  • Wave-based enemy spawning and progression
  • Multiple tower types with unique roles and stats
  • Expanded gameplay logic built on top of tutorial foundations

Play the WebGL Build

The game is fully playable in your browser through the embedded itch.io WebGL build below.

Development Notes

This project helped me strengthen my understanding of Unity’s component-based workflow, enemy AI, wave systems, and balancing. Building all the assets myself also gave me full control over the visual identity and allowed me to design models that fit the gameplay needs.
