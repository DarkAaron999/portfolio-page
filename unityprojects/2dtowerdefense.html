2D Tower Defense

A 2D tower defense game built in Unity. I created all of the code and art assets, including towers, enemies, UI, and gameplay systems.

Overview

2D Tower Defense is a strategy game where players place towers on wooden tiles to stop waves of enemies from reaching the castle. I created all of the visual assets and coded the gameplay systems, including tower placement, enemy pathing, wave progression, and castle health.

Features

  • Click‑to‑place tower system with tile‑based placement
  • Multiple tower types with unique attack behaviors
  • Enemy waves that increase in difficulty
  • Castle health system that ends the game when depleted
  • Fully custom 2D art assets for towers, enemies, and UI

Development Notes

This project strengthened my understanding of tower placement logic, enemy pathing, wave progression, and 2D asset creation. Building both the visuals and gameplay systems allowed me to create a readable and balanced tower defense experience.
