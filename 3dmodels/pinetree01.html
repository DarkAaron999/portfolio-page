Pine Tree

Stylized pine tree created using high‑poly baking and hand‑painted textures

This stylized pine tree was created using a hybrid workflow: high‑poly sculpting for the branches, baking onto a flat plane for leaf detail, and hand‑painted textures for the final look. The normal map was generated using Materialize from the baked image exported from Maya.
